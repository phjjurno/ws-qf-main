민감한 PDF, 온라인에서 안전하게 다루는 법

PDF를 합치거나 줄이려고 검색하면 나오는 사이트는 대부분 파일을 자기 서버로 올려 받아 처리합니다. 계약서나 신분증 사본처럼 민감한 문서를 다룰 때는 그 차이를 알고 고르는 것이 좋습니다.

wsQf 운영팀 · 2026년 11월 4일

온라인 PDF 도구는 보통 이렇게 동작합니다

일반적인 온라인 PDF 서비스는 파일 업로드 → 서버에서 처리 → 결과 다운로드 순서로 동작합니다. 대부분 일정 시간이 지나면 파일을 지운다고 안내하지만, 파일이 어느 나라 서버를 거치는지, 실제로 언제 지워지는지, 로그에 무엇이 남는지는 이용자가 확인하기 어렵습니다. 흔한 문서라면 큰 문제가 아니지만 계약서, 신분증 사본, 급여·의료 관련 서류라면 이야기가 달라집니다.

wsQf는 브라우저 안에서 처리합니다

wsQf의 모든 PDF 도구는 여러분의 브라우저 안에서 동작합니다. 페이지를 열 때 PDF를 다루는 프로그램(pdf-lib, pdf.js)이 브라우저로 함께 내려오고, 합치기·압축·번호 넣기·도장 찍기·영수증 정리는 모두 그 프로그램이 기기 안에서 처리합니다. 파일은 네트워크로 나가지 않습니다.

  • 올린 파일은 브라우저 메모리에만 있고, 탭을 닫거나 새로고침하면 사라집니다.
  • wsQf가 기기에 남기는 것은 다크·라이트 화면 설정 하나뿐입니다. (페이지 광고의 쿠키는 개인정보처리방침에 따로 안내합니다.)
  • 회원가입이 없어서 계정에 파일 기록이 쌓이지도 않습니다.

직접 확인하는 방법

말로만 믿을 필요는 없습니다. PC의 크롬이나 엣지에서 직접 확인할 수 있습니다.

  1. wsQf를 열고 키보드 F12를 누릅니다. 개발자 도구가 열립니다.
  2. 상단의 'Network(네트워크)' 탭을 고르고, 목록을 비웁니다.
  3. PDF를 보관함에 올리고 아무 도구나 실행합니다.
  4. 목록에 올린 파일 크기만 한 업로드 요청이 생기는지 봅니다. 생기지 않습니다. 광고나 글꼴 같은 페이지 자체의 요청은 보일 수 있지만, 여러분의 파일을 담아 보내는 요청은 없습니다.

민감한 문서를 다룰 때의 점검 목록

1. 파일 이름에 개인정보를 넣지 마세요

파일 이름은 메일 미리보기, 메신저 알림, 클라우드 목록에 그대로 보입니다. 홍길동_주민번호_사본.pdf 같은 이름보다 신분증사본_2026.pdf처럼 바꿔 두세요. wsQf의 「파일명 변경」 도구로 다운로드 전에 이름을 바꿀 수 있습니다.

2. 필요 이상의 정보는 원본 단계에서 가리세요

제출처가 요구하지 않는 주민등록번호 뒷자리나 계좌번호는 원본을 만드는 단계에서 지우는 것이 가장 확실합니다. PDF 위에 검은 네모를 덮는 방식은 편집 프로그램에 따라 아래 글자가 그대로 남아 있어 복사하면 드러나는 경우가 있으니 주의하세요.

3. 공유 전에 결과물을 한 번 열어 보세요

합친 순서, 빠진 페이지, 도장 위치를 확인하는 데 1분이면 충분합니다. 잘못 보낸 파일은 되돌리기 어렵습니다.

4. 공용 PC에서는 흔적을 정리하세요

도서관이나 사무실 공용 PC라면 작업 후 다운로드 폴더와 휴지통을 비우고, 브라우저의 다운로드 기록도 지우세요. wsQf가 파일을 보관하지 않아도, 내려받은 결과 파일은 그 PC에 남습니다.

5. 원본은 따로 보관하세요

특히 압축은 페이지를 이미지로 바꾸기 때문에 글자 검색이 안 되는 사본이 만들어집니다. 편집본만 남기고 원본을 지우지 마세요.

자주 묻는 질문

광고가 제 파일 내용을 보나요?

아니요. 페이지의 광고는 개인정보처리방침에 적힌 광고 쿠키 범위에서 동작하고, wsQf는 파일 내용을 광고 사업자를 포함한 누구에게도 전달하지 않습니다. 파일은 브라우저 메모리 안에만 있습니다.

휴대폰에서도 똑같이 안전한가요?

네. 휴대폰 브라우저에서도 같은 방식으로 기기 안에서 처리됩니다. 다만 휴대폰은 메모리가 작아서 아주 큰 파일은 처리 중 멈출 수 있습니다.

작업하다 탭을 닫으면 어떻게 되나요?

보관함의 파일과 작업 내용이 모두 사라집니다. 보관함에 파일이나 영수증이 남아 있으면 닫기 전에 브라우저가 한 번 확인합니다.

암호가 걸린 PDF는 왜 안 열리나요?

wsQf는 암호를 풀거나 우회하는 기능을 제공하지 않습니다. 정당한 권한이 있는 파일이라면 원래 프로그램에서 암호를 해제한 사본을 만들어 올려 주세요.

파일 보관함에 PDF를 올려서 모든 도구를 브라우저 안에서 써 보세요.
