PDF 합치기: 여러 파일을 원하는 순서로 하나로 묶는 법

메일에 첨부를 여러 개 붙이면 받는 쪽은 순서를 헷갈리고, 제출 시스템은 파일 하나만 받는 경우가 많습니다. 흩어진 PDF를 의도한 순서로 한 파일에 묶는 과정을 처음부터 끝까지 정리했습니다.

wsQf 운영팀 · 2026년 11월 4일

이럴 때 필요해요

  • 견적서와 계약서를 한 번에 보낼 때 — 받는 사람이 파일을 따로 열어 맞춰 보지 않아도 됩니다.
  • 장별로 스캔한 문서를 정리할 때 — 복합기나 휴대폰 스캔 앱이 페이지마다 파일을 따로 만든 경우가 흔합니다.
  • 제출 시스템이 파일 하나만 받을 때 — 지원서·증빙 서류를 한 파일로 올리라는 곳이 많습니다.
  • 회의 자료를 배포할 때 — 안건 순서대로 묶어 두면 인쇄도 한 번에 끝납니다.

합치는 방법

  1. 파일 보관함에 PDF를 올립니다. 업로드 영역에 끌어다 놓거나 클릭해서 여러 개를 한꺼번에 고를 수 있습니다. PDF만 받으며 파일 하나당 50MB까지입니다. 이름과 크기가 똑같은 파일은 같은 파일로 보고 한 번만 올라갑니다.
  2. 왼쪽 도구 목록에서 「PDF 합치기」를 엽니다. 보관함에 올린 파일이 목록으로 보입니다.
  3. 합칠 파일에 체크합니다. 두 개 이상 골라야 합니다. 체크하지 않은 파일은 결과에서 빠집니다.
  4. ↑ ↓ 버튼으로 순서를 정합니다. 목록 맨 위에 있는 파일부터 차례로 이어 붙습니다.
  5. 「저장 파일명」을 적습니다. 비워 두면 '합친문서'라는 이름으로 저장됩니다.
  6. 「선택한 PDF 합쳐서 다운로드」를 누릅니다. 처리는 브라우저 안에서 끝나고 결과 파일이 바로 내려받아집니다.

합친 파일은 이렇게 만들어져요

합치기는 각 PDF의 페이지를 원본 그대로 복사해서 이어 붙입니다. 그래서 글자를 선택하거나 검색하는 기능이 그대로 살아 있고, 화질도 변하지 않습니다. A4 세로 문서와 가로로 만든 표를 섞어 합쳐도 각 페이지는 원래 크기와 방향을 유지합니다.

다만 파일 단위로 합쳐진다는 점을 기억하세요. 각 파일의 모든 페이지가 들어가고, 그중 일부 페이지만 골라 빼는 기능은 없습니다. 필요 없는 페이지가 섞여 있다면 원본을 만든 프로그램에서 먼저 정리해 두는 편이 깔끔합니다. 또 원본에 있던 책갈피(목차 패널)는 합친 파일에 남지 않을 수 있습니다.

순서를 덜 만지는 요령

합치기 목록은 보관함에 올린 순서대로 만들어집니다. 보관함의 이름순·크기순 정렬은 보관함 화면을 보기 편하게 바꿀 뿐 합치는 순서에는 영향을 주지 않으니, 처음부터 넣고 싶은 순서대로 올리면 ↑↓ 조정이 거의 필요 없습니다. 파일명 앞에 01_, 02_처럼 번호를 붙여 두면 목록에서 확인하기도 쉽습니다.

합친 다음에 할 일

합친 결과는 바로 다운로드되고 보관함에는 따로 추가되지 않습니다. 이어서 페이지 번호를 넣거나 용량을 줄이려면, 내려받은 파일을 다시 보관함에 올린 뒤 해당 도구를 쓰면 됩니다. 스캔본을 여러 개 합치면 용량이 메일 첨부 한도를 넘기 쉬우니, 보내기 전에 크기를 한 번 확인해 보세요.

막혔을 때

  • "합칠 파일을 2개 이상 선택해 주세요" — 체크된 파일이 하나뿐입니다. 합칠 파일을 모두 체크했는지 확인하세요.
  • 파일이 보관함에 안 올라가요 — 암호가 걸린 PDF는 열 수 없습니다. 암호를 해제한 사본을 만들어 올려 주세요. 50MB를 넘는 파일도 올라가지 않습니다.
  • 합치는 도중 멈춘 것 같아요 — 모든 처리를 기기 안에서 하기 때문에 수백 페이지짜리 파일 여러 개는 시간이 걸리고 메모리를 많이 씁니다. 휴대폰보다 PC가 안정적이고, 다른 탭을 닫으면 도움이 됩니다.

자주 묻는 질문

합친 PDF에서도 글자를 선택하고 검색할 수 있나요?

네. 페이지를 그림으로 바꾸지 않고 원본 그대로 복사해 붙이기 때문에 원래 되던 글자 선택·검색은 그대로 됩니다.

몇 개까지 합칠 수 있나요?

정해진 개수 제한은 없습니다. 다만 브라우저가 기기 메모리를 써서 처리하므로 파일이 아주 많거나 크면 느려질 수 있습니다. 파일 하나당 50MB까지 올릴 수 있습니다.

특정 페이지만 골라서 합칠 수 있나요?

지금은 파일 단위로만 합쳐집니다. 일부 페이지만 쓰려면 원본에서 그 페이지만 따로 PDF로 저장한 뒤 합쳐 주세요.

파일이 서버로 올라가나요?

아니요. 합치는 작업은 전부 브라우저 안에서 이뤄지고 파일은 외부로 전송되지 않습니다. 자세한 내용은 민감한 PDF 안전하게 다루기에 정리해 두었습니다.
