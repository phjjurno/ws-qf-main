PDF 파일명 짓는 법: 제출·공유할 때 헷갈리지 않는 이름 규칙

받는 사람은 파일을 열기 전에 이름부터 봅니다. 메일 첨부 목록, 메신저 알림, 담당자의 다운로드 폴더에서 내 파일이 무엇인지 한눈에 보이게 하는 이름 규칙과, 이미 만든 PDF의 이름을 깔끔하게 바꾸는 방법을 정리했습니다.

wsQf 운영팀 · 2026년 11월 9일

이름이 왜 중요할까요

담당자 한 명이 하루에 받는 첨부 파일은 수십 개입니다. 스캔0012.pdf, 문서1.pdf, 최종_수정본(2).pdf 같은 이름은 열어 보기 전까지 내용을 알 수 없고, 다운로드 폴더에 들어가는 순간 다른 사람의 파일과 섞입니다. 이름만 잘 지어도 "어떤 파일이 최신이냐"는 되물음과 잘못된 파일을 보내는 실수가 크게 줄어듭니다.

기본 공식: 무엇을 · 누가 · 언제

대부분의 상황에서는 아래 세 가지를 밑줄(_)로 이어 붙이면 충분합니다.

요소예시이유
문서 종류견적서, 재직증명서, 포트폴리오열지 않아도 무슨 파일인지 알 수 있습니다
대상·작성자홍길동, A사, 3팀여러 사람의 파일이 한 폴더에 모일 때 구분됩니다
날짜20261109 또는 2026-11-09여러 버전 중 최신본을 바로 고를 수 있습니다

예를 들면 견적서_A사_20261109.pdf, 재직증명서_홍길동_2026-11.pdf처럼 씁니다. 날짜는 연-월-일 순서로, 월과 일은 두 자리로 적어야 이름순 정렬을 했을 때 시간 순서와 일치합니다. 11.9나 9월3일처럼 쓰면 정렬이 뒤죽박죽이 됩니다.

버전은 '최종' 대신 번호로

'최종', '진짜최종', '수정본'은 다음 수정이 생기는 순간 의미를 잃습니다. 버전이 여러 번 오갈 문서라면 _v1, _v2처럼 번호를 붙이거나 날짜를 갱신하세요. 열 개를 넘길 것 같다면 _v01처럼 두 자리로 시작하면 정렬이 깨지지 않습니다. 상대에게 보내는 마지막 파일에는 버전 표시를 빼고 날짜만 남기는 것도 깔끔한 방법입니다.

피해야 할 것

  • 쓸 수 없는 문자 — \ / : * ? " < > |는 윈도우에서 파일 이름에 쓸 수 없습니다. wsQf는 이 문자들을 자동으로 지워서 저장합니다.
  • 개인정보 — 주민등록번호, 전화번호, 계좌번호는 이름에 넣지 마세요. 파일 이름은 메일 미리보기와 클라우드 목록에 그대로 노출됩니다.
  • 지나치게 긴 이름 — 일부 제출 시스템과 압축 프로그램은 긴 이름을 잘라 내거나 오류를 냅니다. 30자 안팎이면 충분합니다.
  • 앞뒤 공백과 연속 마침표 — 눈에 잘 띄지 않아 같은 이름처럼 보이는 파일이 두 개 생기기 쉽습니다.

제출처가 형식을 정해 줬다면 그대로

"지원분야_성명.pdf"처럼 제출처가 이름 형식을 지정했다면 위 공식보다 그 형식이 우선입니다. 담당자가 이름으로 파일을 자동 분류하는 경우가 많아서, 띄어쓰기 하나만 달라도 누락될 수 있습니다. 공고문의 예시를 복사해서 빈칸만 바꾸는 방식이 가장 안전합니다.

wsQf에서 이름 바꾸기

  1. 파일 보관함에 PDF를 올립니다. 여러 개를 한 번에 올려도 됩니다.
  2. 「파일명 변경」 도구를 엽니다. 보관함의 파일마다 이름 입력 칸이 보입니다. 확장자 .pdf는 자동으로 붙으니 앞부분만 고치면 됩니다.
  3. 「이름 저장」을 누르면 바뀐 이름이 합치기·압축·페이지 번호 같은 다른 도구 목록에도 그대로 반영됩니다.
  4. 「다운로드」를 누르면 입력 칸에 적힌 이름으로 바로 내려받습니다.

다른 도구는 결과 파일 이름 뒤에 작업 내용을 붙입니다. 압축하면 _압축, 페이지 번호를 넣으면 _번호, 도장을 찍으면 _도장이 붙습니다. 원본과 결과물이 섞이지 않게 하려는 것이지만, 제출할 때는 이 꼬리표를 떼고 정해진 이름으로 바꿔 두는 편이 깔끔합니다. 작업을 모두 마친 결과 파일을 보관함에 다시 올려 이름만 바꿔 내려받으면 됩니다.

자주 묻는 질문

한글 파일 이름을 써도 되나요?

대부분의 메일과 제출 시스템은 한글 이름을 문제없이 받습니다. 다만 해외 시스템이나 오래된 업로드 페이지에서 이름이 깨지는 경우가 있으니, 영문을 요구하는 곳에는 Portfolio_HongGildong_2026.pdf처럼 영문으로 맞춰 주세요.

띄어쓰기와 밑줄 중 무엇이 좋나요?

밑줄이나 하이픈을 권합니다. 띄어쓰기는 링크로 공유될 때 %20으로 바뀌어 보이고, 일부 시스템에서 이름이 잘리는 원인이 됩니다.

이름을 바꾸면 파일 내용도 바뀌나요?

아니요. 파일명 변경은 이름만 바꾸고 PDF 내용은 그대로 둡니다. 문서 안에 저장된 제목 정보(속성)도 건드리지 않습니다.

보관함에 PDF를 올리고 새 이름을 적은 뒤 바로 다운로드해 보세요.
