PDF 용량 줄이기: 압축 강도 고르는 법과 꼭 알아둘 점

업로드 제한에 걸린 PDF를 줄일 때 가장 흔한 실수는 '아무 설정으로나 일단 줄이고 원본을 지우는 것'입니다. 어떤 파일이 잘 줄어드는지, 강도는 어떻게 고르는지, 압축하면 무엇을 잃는지 먼저 알고 쓰면 실패가 없습니다.

wsQf 운영팀 · 2026년 11월 4일

압축이 잘 되는 파일, 안 되는 파일

wsQf의 압축은 각 페이지를 이미지(JPEG)로 다시 그려서 새 PDF로 묶는 방식입니다. 페이지 크기는 원본 그대로 유지됩니다. 이 방식은 파일의 성격에 따라 효과가 크게 갈립니다.

  • 효과가 큰 파일 — 복합기나 휴대폰 앱으로 스캔한 문서, 사진이 많이 들어간 카탈로그나 포트폴리오. 원래 고해상도 이미지 덩어리라 크게 줄어듭니다.
  • 효과가 작거나 없는 파일 — 워드·한글·엑셀에서 'PDF로 저장'한 글자 위주의 문서. 이미 작게 만들어져 있어서 이미지로 바꾸면 오히려 커지기도 합니다.

압축 결과가 원본보다 크거나 같으면 wsQf는 파일을 내려받지 않고 "이 파일은 이미 충분히 작습니다"라고 알려 줍니다. 쓸모없는 사본이 생기지 않도록 일부러 그렇게 만들었습니다.

강도는 이렇게 고르세요

강도처리 방식어울리는 경우
약하게 (화질 우선)원본의 2배 해상도로 그리고 JPEG 품질 85%인쇄할 문서, 작은 글씨·도면·표가 많은 문서
보통 (권장)1.5배 해상도, 품질 70%대부분의 메일 첨부와 서류 제출
강하게 (용량 우선)1.1배 해상도, 품질 50%업로드 제한이 빡빡할 때, 화면으로만 볼 자료

처음에는 보통으로 해 보고, 목표 용량에 못 미치면 강하게로 다시 압축하는 순서를 권합니다. 이때는 이미 압축한 파일이 아니라 원본을 다시 압축하세요. 압축본을 또 압축하면 화질은 계속 떨어지는데 용량은 거의 줄지 않습니다.

압축하는 방법

  1. 파일 보관함에 PDF를 올립니다. 파일 하나당 50MB까지입니다.
  2. 「PDF 압축」 도구를 열고 「압축할 파일」을 고릅니다.
  3. 압축 강도를 선택합니다. 위 표를 참고하세요.
  4. 「압축해서 다운로드」를 누릅니다. 페이지별 진행 상황이 표시되고, 끝나면 압축 전후 용량과 감소율을 알려 줍니다. 파일명 끝에는 _압축이 붙습니다.

압축하면 잃는 것 — 원본은 꼭 남겨 두세요

  • 페이지가 이미지가 되므로 글자를 선택·복사·검색할 수 없게 됩니다.
  • 문서 안의 링크도 더 이상 눌리지 않습니다.
  • 제출처가 '텍스트 검색이 가능한 PDF'를 요구한다면 압축본을 내면 안 됩니다. 이런 곳은 보통 용량 제한도 넉넉하니 원본을 그대로 내는 편이 맞습니다.

목표 용량을 맞추는 요령

먼저 제출처의 한도를 확인하세요. 대표적으로 Gmail은 첨부 파일을 25MB까지 받고, 공공기관이나 채용 사이트의 업로드 칸은 그보다 훨씬 작은 경우가 많습니다. 강하게로도 부족하다면 압축보다 페이지 수를 줄이는 쪽이 효과적입니다. 꼭 필요한 페이지만 남기거나, 파일을 나눠 보내는 방법을 검토해 보세요.

페이지 번호나 도장도 넣을 계획이라면 압축을 먼저 하는 것이 좋습니다. 압축은 페이지를 통째로 이미지로 바꾸기 때문에, 번호와 도장을 나중에 얹어야 또렷하게 남습니다. 페이지 번호와 도장·서명 가이드도 참고하세요.

자주 묻는 질문

화질이 얼마나 떨어지나요?

보통 강도에서는 화면으로 읽거나 일반 프린터로 출력하는 데 무리가 없는 수준입니다. 작은 글씨가 많은 문서라면 약하게를 고르고, 결과를 확대해서 글씨가 뭉개지지 않았는지 확인한 뒤 보내세요.

압축했는데 용량이 안 줄었어요.

글자 위주로 만들어진 PDF는 이미 작아서 이미지 방식으로는 줄일 여지가 없습니다. 이 경우 결과가 원본보다 크면 다운로드하지 않고 알려 드립니다. 페이지 수를 줄이는 방법을 써 보세요.

압축 중에 실패했다고 나와요.

파일이 손상됐거나 기기 메모리가 부족한 경우입니다. 페이지가 아주 많은 파일은 PC에서, 다른 탭을 닫은 상태로 다시 시도해 주세요. 암호가 걸린 PDF는 처리할 수 없습니다.

압축한 파일에 다시 페이지 번호를 넣을 수 있나요?

네. 압축본을 보관함에 다시 올린 뒤 페이지 번호나 도장 도구를 쓰면 됩니다. 이렇게 압축 → 편집 순서로 하면 번호와 도장이 또렷하게 남습니다.

압축할 파일을 보관함에 올리고 강도만 고르면 됩니다.
