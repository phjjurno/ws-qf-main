상황별 가이드

도구 하나로 끝나지 않는 일들, 예를 들어 지원서 제출이나 경비 정산처럼 여러 도구를 이어서 써야 하는 상황을 처음부터 끝까지 정리했습니다.

제출 전 체크리스트용량·순서·이름·서명 5분 점검 입사지원 PDF 준비이력서·포트폴리오 합치기와 용량 경비 정산 증빙 만들기영수증·카드 내역·정산서를 한 파일로 스캔 PDF가 너무 클 때다시 스캔할지 압축할지 판단하기 PDF 파일명 짓는 법날짜·이름·버전, 헷갈리지 않는 규칙

어떤 순서로 쓰면 좋을까

여러 작업을 한 파일에 이어서 해야 한다면 합치기 → 압축 → 페이지 번호·도장 순서가 가장 깔끔합니다. 합치기는 원본 페이지를 그대로 이어 붙이고, 압축은 페이지를 이미지로 다시 그리기 때문에, 번호와 도장을 마지막에 얹어야 또렷하게 남습니다. 각 단계의 결과 파일은 다운로드되므로 다음 도구를 쓰려면 다시 파일 보관함에 올리면 됩니다.

모든 처리는 내 기기 안에서

wsQf의 도구는 파일을 서버로 보내지 않고 브라우저 안에서 처리합니다. 계약서나 신분증 사본처럼 민감한 문서를 다룰 때 무엇을 확인하면 좋은지는 민감한 PDF 안전하게 다루기에 정리했습니다.
