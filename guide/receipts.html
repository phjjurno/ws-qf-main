영수증 정리: 사진으로 A4 증빙 PDF 만들고 합계 내기

정산하려고 영수증 사진을 문서에 하나씩 붙이고 크기를 맞추고 계산기를 두드리는 일은 매달 반복됩니다. 사진만 올리면 A4에 가지런히 배치하고 합계까지 적어 주는 방법을 정리했습니다.

wsQf 운영팀 · 2026년 11월 4일

이럴 때 필요해요

  • 출장비·업무 경비 정산 — 회사에 영수증 증빙을 A4로 제출해야 할 때
  • 법인카드 사용 내역 증빙 — 사용처와 용도를 함께 적어 내야 할 때
  • 프리랜서·개인사업자 지출 정리 — 달마다 쌓이는 영수증을 한 파일로 모아 둘 때
  • 모임 회비 정산 — 누가 얼마 썼는지 사진과 합계를 함께 공유할 때

먼저, 사진을 잘 찍어 두세요

결과물의 품질은 사진에서 거의 결정됩니다.

  • 영수증을 평평하게 펴서 어두운 바탕 위에 놓으면 테두리가 잘 구분됩니다.
  • 그림자가 지지 않게 밝은 곳에서, 영수증 전체가 다 나오게 정면에서 찍습니다.
  • 금액과 날짜 글씨에 초점이 맞았는지 확대해서 확인합니다.
  • 감열지 영수증은 시간이 지나면 글씨가 바래니 받은 날 바로 찍어 두는 것이 안전합니다.

아이폰 사진이 안 올라간다면

wsQf는 JPG·PNG·WEBP 사진을 받습니다. 아이폰 카메라는 기본 설정에서 HEIC 형식으로 저장하기 때문에 올라가지 않을 수 있습니다. 설정 › 카메라 › 포맷에서 '높은 호환성'을 고르면 이후부터 JPG로 저장됩니다. 이미 찍은 사진은 화면을 캡처해서 올리는 방법도 있습니다.

정리하는 방법

  1. 「영수증 정리」 도구를 열고 사진을 올립니다. 여러 장을 한꺼번에 끌어다 놓을 수 있습니다. 올린 순서대로 배치되니 날짜순으로 올리면 확인하기 편합니다.
  2. 영수증마다 금액과 메모를 적습니다. 금액은 숫자만 읽어서 12,000이나 12000원처럼 적어도 됩니다. 잘못 올린 사진은 「삭제」로 뺍니다.
  3. 「문서 제목」을 적습니다. 각 장 맨 위에 찍히고 파일 이름에도 쓰입니다. 비워 두면 '영수증 정리'가 됩니다.
  4. 「장당 영수증 수」를 고릅니다. 아래 표를 참고하세요.
  5. 「미리보기」로 배치를 확인한 뒤 「A4로 정렬해서 PDF 다운로드」를 누릅니다. 파일 이름은 제목_날짜 형식으로 저장됩니다.

한 장에 몇 개씩 넣을까

장당 수어울리는 경우
2장길이가 긴 영수증, 글씨가 작은 카드 전표, 확대해서 봐야 하는 세금계산서 사진
4장 (기본)일반 식당·편의점 영수증. 크기와 매수의 균형이 가장 좋습니다
6장짧은 영수증이 많을 때, 출력 매수를 줄이고 싶을 때

합계와 메모 활용하기

금액을 적으면 화면 아래에 합계가 바로 계산되고, "영수증 10건 중 8건 금액 입력"처럼 아직 금액을 안 적은 영수증이 몇 건인지 알려 줍니다. 완성된 PDF에는 각 장 아래에 페이지 번호가, 마지막 장 아래에 합계가 들어갑니다.

메모 칸에는 날짜·사용처·용도를 짧게 적어 두세요. 예를 들어 "11/3 거래처 미팅 식대"처럼 적어 두면 정산 담당자가 영수증을 하나하나 확인하지 않아도 되고, 몇 달 뒤 내가 다시 볼 때도 바로 알 수 있습니다.

금액은 직접 적는 방식입니다

사진에서 금액을 자동으로 읽어 오는 기능(OCR)은 없습니다. 대신 잘못 인식된 숫자가 섞일 걱정이 없고, 직접 확인한 금액만 합계에 들어갑니다. 또 회사나 세무 규정에 따라 정리본과 별도로 원본 영수증이나 카드 전표를 보관해야 할 수 있으니, 제출 규정을 확인하세요.

자주 묻는 질문

PDF에서 한글이 깨지지 않나요?

제목·금액·메모를 이미지로 그려 넣기 때문에 어떤 기기에서 열어도 한글이 깨지지 않습니다.

화질은 어느 정도인가요?

A4 한 장을 약 150dpi로 만듭니다. 인쇄했을 때 영수증 글씨를 읽기에 충분하면서 파일이 지나치게 커지지 않는 수준입니다.

영수증 순서를 바꿀 수 있나요?

올린 순서대로 배치됩니다. 순서를 바꾸려면 해당 사진을 삭제하고 원하는 순서에 맞춰 다시 올려 주세요.

사진이 서버에 저장되나요?

아니요. 사진과 금액은 브라우저 안에서만 처리되고, 탭을 닫으면 사라집니다. 작업 중에는 새로고침하지 않도록 주의하세요.
